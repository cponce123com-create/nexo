# Referencias de proyectos abiertos

Revisión basada en las páginas de los proyectos; no se ha copiado código externo. Las funcionalidades citadas deben evaluarse en el código y las versiones concretas antes de adoptarlas.

| Proyecto | Ideas útiles | Encaje y atención |
| --- | --- | --- |
| [LinkStack](https://github.com/LinkStackOrg/LinkStack) | Registro multiusuario, perfiles, temas y panel administrativo | Laravel/PHP. Licencia AGPL-3.0; revisar obligaciones de distribución y acceso al código si se adapta para servicio en red. |
| [LinkForge](https://github.com/linkforges/linkforge) | Constructor de bloques, temas y vista móvil; análisis | Laravel/PHP. Declara MIT; revisar licencias de dependencias y avisos antes de copiar archivos. |
| [OneLink](https://github.com/Abhi1264/onelink) | Subdominios, orden de enlaces y estadísticas | Proyecto pequeño; revisar mantenimiento y licencia concreta antes de usar código. |
| [GrapesJS](https://github.com/GrapesJS/grapesjs) | Editor visual extensible de arrastrar y soltar | Es una biblioteca, no resuelve usuarios ni publicación; valorar complejidad y seguridad de HTML antes de integrar. |

Primero construir bloques propios limitados y seguros; estudiar un editor libre completo solo si hay necesidad real. Las ideas de las interfaces pueden orientar NEXO sin copiar código. No se garantiza compatibilidad de licencias sin una revisión de los archivos y dependencias realmente incorporados.
